# Daily DSP Operation Check

Streamlit app for generating daily route monitoring Excel reports.

## Input Requirements

The source Excel must contain:

- Column B = Route
- Column J = Status
- Column L = Status changed time

Optional:

- A column name containing Driver will be used as DriverName
- A column name containing Flee will be used as FleeName

## Current Logic

- Total = all tracking numbers in the route
- New = Status == NEW
- OFD Total = Total - New
- Success(Delivered) = Status == DELIVERED
- Failed(*FAIL*) = Status contains FAIL
- Remaining(OFD) = Status == OUT_FOR_DELIVERY
- OFD(CompletionRate) = Success(Delivered) / OFD Total

## Sheets Generated

- RouteMonitor
- Summary
- Exceptions
- 3pm check
- 6pm check
- Meta

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Cloud

1. Push this repo to GitHub.
2. Streamlit Cloud -> New app -> select repo.
3. Main file path: `app.py`.
4. Deploy.
